# Cobble Co-op Bug Tracker

This repository is only for reporting problems with Cobble Co-op.

Before opening a report, please check the existing issues. If somebody already reported the same
problem, add any useful information there instead of creating another issue.

## Before reporting

- Make sure all required mods are installed and use compatible versions.
- Try the latest available Cobble Co-op version.
- Keep the `latest.log` file from the session where the problem happened.
- Write down what both players were doing when the bug appeared.

## Good bug reports include

- A short explanation of what went wrong.
- Clear steps that reproduce the problem.
- The versions of Cobble Co-op, Cobblemon, RCT and RCT API.
- `latest.log` and the crash report, when one exists.
- Screenshots or video for menu and visual problems.
- The active handicaps when the problem happened during a co-op battle.

Open the **Issues** tab and choose **Bug report** to begin.

Please do not include account information, server addresses, access tokens or anything else that
should remain private in logs or screenshots.

## Not handled here

Problems that also happen without Cobble Co-op should be reported to Cobblemon or Radical Cobblemon
Trainers instead.
